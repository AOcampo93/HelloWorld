# Hello World

## Overview

This project is my first program for CSE 310 - Applied Programming. It is a simple JavaScript program that runs in Node.js and prints "Hello World" to the console. After that, it prints a short personal greeting with today's date.

The purpose of this project is to learn the basics of JavaScript and to practice the Git and GitHub workflow I will use for the rest of the course: creating a local repository, making commits, and pushing the code to a public GitHub repository.

To run the program, install [Node.js](https://nodejs.org/) and run this command from the project folder:

```bash
node hello_world.js
```

Expected output:

```
Hello World
Greetings from Arturo! Today is Saturday, September 19, 2026.
```

(The date will match the day you run the program.)
